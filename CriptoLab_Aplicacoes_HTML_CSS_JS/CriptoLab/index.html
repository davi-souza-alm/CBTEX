Quatro ideias essenciais

01 / SIGILO

Confidencialidade

Somente quem possui a chave adequada deve conseguir ler o conteúdo protegido.

02 / INTEGRIDADE

Conteúdo intacto

Hashes e tags de autenticação ajudam a detectar alterações nos dados.

03 / IDENTIDADE

Autenticidade

Assinaturas e certificados ajudam a relacionar uma chave a uma identidade.

04 / RESPONSABILIDADE

Não repúdio

Uma assinatura verificável pode apoiar evidências de autoria, dependendo da gestão das chaves e do contexto jurídico.

Sobre este laboratório

Projeto acadêmico para fins educacionais. As operações são realizadas localmente no navegador por meio da Web Crypto API. A demonstração de assinatura não substitui uma infraestrutura de certificação ICP-Brasil, e as chaves privadas geradas aqui não devem ser usadas para documentos reais.
