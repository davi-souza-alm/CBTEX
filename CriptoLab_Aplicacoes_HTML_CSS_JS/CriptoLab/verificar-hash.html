O conteúdo ainda está intacto?

Compare o hash SHA-256 esperado com o hash calculado a partir da mensagem ou arquivo recebido. Uma diferença indica que os dados não são iguais.

Interpretação

O hash permite detectar diferenças quando o valor esperado é confiável. Como não há segredo no SHA-256, um atacante que consiga substituir o conteúdo e o hash publicado pode enganar uma comparação isolada. Para comprovar autoria, use assinatura digital.
